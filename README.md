# Gun Shooter 2000

A compact browser shooter inspired by arena survival games, built as a single static HTML5 site.

Features:
- Player movement with WASD
- Mouse aim and click-to-fire shooting
- Wave system with increasing enemy pressure
- Boss fights every 5th wave
- Score and high score tracking
- Health bar, power-ups, and progression
- Simple login flow with saved local progress

How to run locally:
1. Open `index.html` in a browser, or run a small local web server from this folder.
2. Example:
   `python3 -m http.server 8000`
3. Visit `http://localhost:8000`

Publishing to GitHub Pages:
1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to Pages.
4. Set the source to the main branch and root folder.
5. Save.
6. Your site will be available at:
   `https://<your-user>.github.io/gun-shooter-2000/`
